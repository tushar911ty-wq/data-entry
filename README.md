# Data Entry Detection System

This project is a smart data entry system that automatically detects previously entered user information.

## Features
- User form submission
- Automatic data saving
- Detects existing users by name/details
- Auto-fills previously entered information
- Reduces repeated manual data entry
- Improves speed and accuracy

## Workflow
1. User fills the form for the first time
2. System stores the data
3. When the same user enters again
4. System detects existing records
5. Previous details are automatically loaded
